# Autodrive Veículos & Tecnologia

Aplicação Next.js de produção para catálogo automotivo, captação de leads e administração do estoque da Autodrive. O domínio `dagobertoeasycar.com.br` continua como endereço temporário publicado pela Vercel.

## Desenvolvimento

1. Copie `.env.example` para `.env.local` e preencha as variáveis.
2. Execute `pnpm install`.
3. Execute `pnpm db:migrate`.
4. Crie o primeiro administrador com `pnpm admin:create`.
5. Execute `pnpm dev`.

O ambiente de produção usa Vercel com banco Neon Postgres. O clone oficial fica em `D:\sitedagobertoeasycar\_envio_github\repo`.
